## 快速开始

1. 下载安装包 **[BsKeyTools.exe](https://github.com/AniBullet/BsKeyTools/releases/latest)**（GitHub 访问慢可用下方网盘）
2. 运行安装程序，勾选要安装的 3ds Max 版本（自动检测本机已安装的版本）
3. 启动 3ds Max，从菜单栏 **BsKeyTools** 打开工具；之后启动时会自动检查新版本

## 核心功能

> 100+ 工具覆盖动画全流程，支持 3ds Max 2014–2026，中英双语界面。完整清单见 [TOOLS_STATISTICS.md](TOOLS_STATISTICS.md)

<table>
<tr>
<td width="50%" valign="top">

### 动画

- **重定向**：FBX / BIP 互转，内置骨骼映射预设（UE5 / Sekiro / DMC5 / 怪猎 等）
- **关键帧**：补间、镜像、烘焙、复制粘贴、帧范围管理
- **轨迹**：运动轨迹可视化编辑、Root Motion 提取

</td>
<td width="50%" valign="top">

### 绑定与蒙皮

- **骨骼**：Biped 工具集、链条/飘带绑定、扭曲骨骼、弹簧控制器
- **蒙皮**：XR 蒙皮工具、权重分区平滑、Skin 拆合、蒙皮换骨
- **表情**：Morpher 滑条、表情控件、Morph 镜像

</td>
</tr>
<tr>
<td width="50%" valign="top">

### 视觉与参考

- **GhostTrails**：残影效果插件（Max 9–2026）
- **AnimRef**：视频/图像序列同步播放，集成 FFmpeg
- **视口**：剪影、洋葱皮、构图框、快速拍屏、多向渲染

</td>
<td width="50%" valign="top">

### 管理与安全

- **备份**：自动备份与版本管理
- **场景**：增强图层管理、批量重命名、批量降版本、场景清理
- **防护**：脚本病毒实时扫描与批量杀毒（BsCleanVirus）

</td>
</tr>
<tr>
<td width="50%" valign="top">

### 动作逆向

- **RE 引擎**：鬼泣5、街霸6、怪猎崛起、鬼武者 等
- **格式**：Havok、ActorX (PSK/PSA)、XnaLara/XPS
- **输出**：批量转换 FBX，打通游戏动作参考工作流

</td>
<td width="50%" valign="top">

### 工作流

- **界面**：灵活停靠、可排序功能按钮、图标/文字切换
- **效率**：时光机快速打开、选择集、动画库
- **扩展**：BsScriptHub 远程脚本平台

</td>
</tr>
</table>
