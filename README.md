## 亮点

- **一个面板**：100+ 工具收进可停靠主面板，支持横向/竖向停靠、图标/文字切换、按钮排序
- **动画重定向**：FBX 与 Biped 互转，内置 UE5、只狼、鬼泣5、怪猎等骨骼映射预设
- **关键帧与轨迹**：补间、镜像、烘焙、复制粘贴、帧范围管理，运动轨迹编辑与 Root Motion 提取
- **绑定与蒙皮**：Biped 工具集、链条/飘带绑定、扭曲骨骼、弹簧控制器、权重平滑、Skin 拆合、蒙皮换骨、Morpher 表情工具
- **视口与参考**：GhostTrails 残影、AnimRef 视频参考同步播放、剪影、洋葱皮、构图框、快速拍屏
- **游戏动作导入**：RE 引擎（鬼泣5、街霸6、怪猎崛起、鬼武者）、Havok、ActorX、XPS，批量转 FBX
- **场景安全**：自动备份、增强图层管理、批量重命名与降版本、脚本病毒实时扫描（BsCleanVirus）
- **开箱即用**：支持 3ds Max 2014–2026，中英双语界面，启动时自动检查更新

完整工具清单见 [TOOLS_STATISTICS.md](TOOLS_STATISTICS.md)。

## 安装

1. 从 [Releases](https://github.com/AniBullet/BsKeyTools/releases/latest) 下载 `BsKeyTools.exe`
2. 运行安装程序，勾选要安装的 3ds Max 版本（自动检测本机已安装的版本）
3. 启动 3ds Max，从菜单栏 **BsKeyTools** 打开工具

| 安装包 | 内容 |
|:---|:---|
| `BsKeyTools.exe` | 全功能插件（推荐） |

## English

BsKeyTools is a free, all-in-one animation toolkit for Autodesk 3ds Max (2014–2026), bundling 100+ tools for animators and technical artists in a single dockable panel:

- **Retargeting**: FBX ↔ Biped conversion with bone-mapping presets (UE5, Sekiro, DMC5, Monster Hunter and more)
- **Keyframes & trails**: tweening, mirroring, baking, frame-range tools, motion trail editing, Root Motion extraction
- **Rigging & skinning**: Biped utilities, chain and ribbon rigs, twist bones, spring controllers, skin weight tools, Morpher helpers
- **Viewport & reference**: GhostTrails, AnimRef video reference, silhouette, onion skin, framing guides, quick playblast
- **Game animation import**: RE Engine titles, Havok, ActorX, XPS, with batch FBX export
- **Scene safety**: auto backup, layer manager, batch rename, MaxScript malware scanner (BsCleanVirus)

To install, download `BsKeyTools.exe` from [Releases](https://github.com/AniBullet/BsKeyTools/releases/latest), run it, select your 3ds Max versions, then open **BsKeyTools** from the 3ds Max menu bar. The UI is available in Chinese and English.
